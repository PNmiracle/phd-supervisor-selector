## 🇺🇸 US/Canada

#### 🇺🇸 美国博士项目筛选 · 体系与口径总则（2026-10-06 姜一丁任务沉淀）

**一、按「院系口径」搜项目，不要只搜「电影系」（CRITICAL）**
美国大学里能承载影视/媒介/表演研究的博士项目**分散在至少 5 类院系**。只按 `Film/Cinema Studies` 一个口径扫，会**系统性漏掉 2-3 倍的项目**：
1. **电影/媒介研究系** —— 最直接（Film & Media Studies、Cinema Studies、Screen Cultures）
2. **表演研究系** —— Theatre & Performance Studies、Performance Studies（Drama 系多为 MFA，但 TAPS/Performance Studies 常设 PhD）
3. **传播学院** —— Communication PhD，分两支：**人文取向**（media studies、media industries，适合文科背景）vs **社科取向**（量化、media psychology，**不适合**人文学科背景的学生）
4. **东亚/亚洲研究系** —— EALC / ALC / EALCS，常有人在电影与视觉文化方向带博，是「华语电影」方向最容易被忽略的入口
5. **视觉文化/艺术史系** —— Visual Studies、History of Art and Visual Culture、Art History（含 Film & Media 方向）

**判断传播类 PhD 是否适合文科背景的快速检验**：看该系课程与师资是否含 media industries / popular culture / critical media studies / cultural studies。若只有 interpersonal communication、media psychology、political communication、量化方法，则不适合。

**二、加州的结构性断档（申请策略必读）**
- **1960 年《加州高等教育总体规划》规定 PhD 授予权专属 UC 系统**。**CSU（California State University，23 所）使命只到硕士**，只能独立授予 Ed.D. / DPT / AuD / DNP / OTD 等**专业博士**；联合授予 PhD 需与 UC 或私立合作，且仅限"现有 PhD 无法满足需求"的领域。
- **后果**：CSU 全部 23 所（SFSU、SJSU、CSULB、CSUF、CSUN、Cal State LA…）影视/传媒学位**最高只到 MFA/MA**。艺术院校（CalArts、AFI、ArtCenter、Otis）同样只有 MFA。中档私校（LMU、Chapman Dodge、Pepperdine、Santa Clara）也只有 MFA。
- **CSU–UC 联合博士存在但领域被限定**（SDSU 集中在生物/化学/工程/地理；Cal State LA×UCLA 是 Special Education）→ **影视/媒介类联合博士为零**。
- **唯一例外**：**Chapman University 有研究型 PhD in Communication**（R2，含 Media and Communication Technology、Media/Film Studies 方向）。
- **SFAI（San Francisco Art Institute）已于 2022-07 永久关闭、2023-04 申请破产清算**，勿引用。
- **策略含义**：在加州，「保底档」对影视研究 PhD **不存在**。保底必须移到其他州。⚠️ **MFA 是创作终端学位，不是研究型博士的跳板**，不要用 MFA 项目当保底。
- **来源**：UC 官方总体规划 https://www.ucop.edu/institutional-research-academic-planning/content-analysis/academic-planning/california-master-plan.html

**四、子代理产出的使用纪律（CRITICAL，2026-10-06 姜一丁加州轮教训）**
并行子代理回来时给出的「研究方向描述」「著作」「职务」「带博证据」，**经常超出个人页上真实存在的内容** —— 它们是综合了搜索摘要、CV、个人站、新闻稿等多源信息后的**概括**，不是页面原文。
- 2026-10-06 加州轮：2 个独立审计官对 52 条记录查出 **15 条 P0**，**全部**源于此。典型：给某教授写「兼博士项目主任」（该职实属他人）、写「deepfake／合成影像」（页面只写 digital technologies）、写「策划过 XX 回顾展」（页面无记载）、写某著作名（页面无著作栏）、**职称写高一级**（页面标 Assistant Professor 而写成 Associate）。
- **强制动作**：撰写备注前，**必须自己 WebFetch 打开该导师的个人页，逐条核对每一个事实性表述**，只写页面上能读到的内容。子代理的概括**只能作为「去这个页面找什么」的线索**，不能直接采信。
- 若某事实只存在于其他页面（新闻稿、CV、系级页），**必须在备注里附上来源链接**；否则不写。
- **职称以个人页原文为准**。若个人页常年未更新（如某些 UCI/Drama 档案停留在 2018 年），标注不确定性，不要凭院系新闻或名录自行升级职称。

**五、美国任务的操作要点（2026-10-06 / 10-07）**
- **Vika API**：POST 创建记录必须传 `{'records': [...]}`（包一层），传裸列表会返回 500 `records value can't be empty array or null`。PATCH 用 `{'records': [...], 'fieldKey': 'name'}`；URL 类型字段用 `fieldKey: 'id'`。
- **⚠️ Vika 单次 `recordIds` 查询上限 100 条**（2026-10-07 发现）：超过 100 个 ID 时**超出的部分被静默丢弃、不报错**（表现为"查出 100 条 / 实际 138 条"）。批量复核必须分批（每批 ≤90 条）。同理 `pageSize` 上限 200 且 `hasMore` 可能缺失（须用 `total` 判断翻页）。
- **UCI 的 `faculty.uci.edu/profile/?facultyId=` 档案更新严重滞后**：实例 Tara Rodman 的档案停留在 2018 年、仍写 Assistant Professor，而系级现名录 `drama.arts.uci.edu/people` 与 UCI 总目录已是 Associate Professor。**判断 UCI 教师职称应以系级现名录或总目录为准**，不要只信该档案系统（本条修正了此前"以个人页原文为准"在该校的误用）。
- **同校新名录残留**：美国大学院系名录常残留已转校/已荣休者（实例：UCSB 名录仍留已转 UCLA 的 Michael Berry 与 Suk-Young Kim；Charles Wolfe 已 Emeritus；Michigan 的 Markus Nornes 已 Emeritus；UChicago 的 Tom Gunning 已 Emeritus；UT Austin 的 Michael Kackman 已转 Notre Dame 教学岗）。**必须打开个人页确认在职状态**，不能只看系级名录。
- **⚠️ 判断页面可用性不能只看字节数**：反爬错误页可能**体积很大**。实例：Georgia State 的 `thearts.gsu.edu` / `fmt.gsu.edu` 返回 **646KB 的 "Site Unavailable" 错误页**（状态码 403），若只用"字节数 > 3000"判断会误判为正常页。**必须同时检查状态码 + 标题 + 页面是否含目标人名**。
- **四所美国学校官网对 curl 反爬，须改用 WebFetch**：Harvard `afvs.fas.harvard.edu`（403 Access Denied）｜Michigan `lsa.umich.edu`（Cloudflare）｜Georgia State `thearts.gsu.edu` / `fmt.gsu.edu`（403）｜Minnesota `cla.umn.edu`（Cloudflare）。另 UT Austin `rtf.utexas.edu` 返回 403（Varnish）。
- **美国项目池的两道硬门槛（申请前必查）**：① **要求申请者已持硕士学位** —— NYU Cinema Studies、UT Austin RTF、UW Seattle Cinema & Media、UCLA Cinema & Media Studies（学生 UCL MA 满足）；② **只招联合学位** —— Yale FMS（须与 10 个系之一联合）、Pittsburgh（须与 English / French / Hispanic / History of Art and Architecture / Slavic 之一联合，且 **English 一系 2026-27 循环暂停招生**）。

## 🍁 加拿大批次专属陷阱（2026-09-24 王灏案例沉淀）（自 SKILL.md 迁入 2026-10-07）


#### 1. 写完必须跑「学校 —— 域名」一致性扫描（否则会漏跨校错链）
**踩坑**：同一条写入脚本里，给「滑铁卢土木」和「西安大略土木」的博士项目页常量取了同名（`PHD_W_CEE`）。
Python 自上而下执行，**后定义的 Western 链接覆盖了 Waterloo 链接**，导致 4 条 Waterloo 记录的「博士申请信息」全挂了 `uwo.ca`。
**规则**：写库脚本里每个学校的链接常量必须唯一命名且带校名缩写（`PHD_UW_CEE` / `PHD_UWO_CEE`）；
写完后**必跑**一次校验：

```python
# 学校 → 允许域名白名单，逐条比对 3 个 URL 字段
ALLOW = {"University of Waterloo": ["uwaterloo.ca"], "Western University": ["uwo.ca"], ...}
# 命中白名单外的学校域名 = 跨校错链，P0 必修
```

#### 2. McMaster：`其他导师信息` 必须带系筛选参数
`https://www.eng.mcmaster.ca/faculty-staff/faculty-directory/`（无参）是**跨系总目录**（含 Dean、化工系主任等），不合格。
改用系级筛选 URL（实测只列本系）：土木 `?filter-department=54`，机械 `?filter-department=65`。
文理类用 `kinesiology.mcmaster.ca/people/faculty/`、`sees.mcmaster.ca/people/faculty/`（本身即系级）。
`www.eng.mcmaster.ca` 在本机 curl 会被代理挡（502），**改用 WebFetch 可正常读**。

#### 3. UAlberta：**不存在系级教师名录**，别去猜 URL
`/engineering/<dept>/people/index.html` 一律是同一个工程院级「Find a Person」检索页（或 404）；
CEE 的 `people/index.html` 实测直接 404。人工/审核建议的"换成系级名录页"是**假修复**。
现实做法：`其他导师信息` 用 `https://www.ualberta.ca/engineering/people/index.html`（可列出人名+系别），
并在反馈里**如实说明该校不设系级名录**。个人页统一用 `apps.ualberta.ca/directory/person/<shortname>`（curl 可读）。
注意 `www.ualberta.ca` 直抓只返回 157 字节 JS 壳，**必须 WebFetch 才能判断 200 是真页还是 404 页**。

#### 4. UBC：院系站全线 bot 防护 → 三条可用通道
`civil.ubc.ca` / `mech.ubc.ca` / `kin.ubc.ca` / `spph.ubc.ca` / `bme.ubc.ca` 对自动访问返回 `Browser Verification` 页（URL 有效，人可打开）。
可读的官方个人页只有：
- `https://www.grad.ubc.ca/researcher/<id>` —— 研究生导师库，含 Research Interests / 招生字段；
- `https://news.ubc.ca/expert/<slug>` —— 媒体专家页，含职称 + 院系 + Expertise + 邮箱（WebFetch 可读，curl 403）；
- `scarp.ubc.ca/directory/<slug>`、`engineering.ok.ubc.ca/about/contact/<slug>/` —— 这两个学院站无防护，可直接读。
⚠️ **`grad.ubc.ca` 把副教授统一标成 `Professor`**（Alex Bigazzi 案例），职称必须以 `news.ubc.ca/expert/` 或院系页交叉核对后再写。

#### 5. 滑铁卢：`experts.uwaterloo.ca` 的职称字段会过期
`experts.uwaterloo.ca/<slug>` 可读、有 Expert In 关键词，但职称栏**长期未更新**（Tesfamariam 写 Assistant Professor、Arami 写 Assistant Professor，实际分别为 Professor / Associate Professor）。
职称一律以 `uwaterloo.ca/<dept>/contacts` 为准；本轮据此纠正 1 条。

#### 6. 备注结尾语气词别批量化
「可以备选一下呢～」若在批内出现 10 次以上会被审核判为模板化。准备 4–5 个等价说法轮换
（可以备选一下呢～ / 可以往后放一放～ / 作为备选看看～ / 可以放后面一点～），同一批内每种不超过 3 次。
另注意：**学生的方向标签必须来自其原话**，不要自造新方向名（本轮误写"运动损伤防护方向"，学生并未提过该方向，已按原话改回）。

#### 7. 📧 补邮箱：McGill 的 `[at]` 混淆 与 UBC 的验证码墙（2026-09-28 沉淀）

```html
<span class="spamspan"><span class="u">lijun.sun</span> [at] <span class="d">mcgill.ca</span></span>
```

解析正则：
```python
SP = re.compile(r'<span class="u">([^<]+)</span>\s*(?:\[at\]|&#64;|@)\s*<span class="d">([^<]+)</span>', re.I)
# → f"{u}@{d}"
```

**图片验证码**（"please complete the captcha below"，要识别图里的瓶子/红点，无法自动通过），换 IP/重试也没用。
